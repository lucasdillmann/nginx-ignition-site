# nginx ignition website

The source code for the product site of **nginx ignition**, a modern, intuitive web interface for the
nginx web server, built for developers and homelab users.

- **Live site:** [nginxignition.app](https://nginxignition.app)
- **Main project:** [github.com/lucasdillmann/nginx-ignition](https://github.com/lucasdillmann/nginx-ignition)
